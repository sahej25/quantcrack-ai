# QuantCrack AI — Basic MVP

A beginner-friendly CAT Quant practice website inspired by common exam-prep workflows. It is an original implementation and does not use Cracku branding, code, or proprietary question content.

## Features
- Six practice topics
- Sample multiple-choice questions with answer checking
- Step-by-step explanations
- 15-minute countdown timer
- Local progress and accuracy tracking
- Responsive layout for desktop and mobile
- No API keys or database required for this first version

## Run it on your computer
1. Extract the ZIP file.
2. Open the `quantcrack-ai` folder.
3. Double-click `index.html` to open it in your browser.

For a more realistic local web server, install Node.js and run `npx serve .` from this folder, then open the local URL it prints.

## Important MVP limitations
- Progress is saved only in the current browser on the current device.
- There is no login, cloud database, payment system, or AI-generated question feature yet.
- Questions are sample practice content; review them before publishing as paid educational material.
